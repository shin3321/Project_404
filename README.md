## 개발 내용

[노션 링크](https://www.notion.so/dalssagi/Project4-33ebf57640cf80408a2afa3b783b093d?source=copy_link)
1. GAS(Gameplay Ability System) 기반 무기 시스템 구현 - GAS 프레임워크 적용
2. 리슨 서버(Listen Server) 멀티플레이 및 네트워크 동기화
3. 단계별 게임 루프 제어 - 로비 -> 일반 필드 파밍 단계 -> 보스방 레이드 단계
4. 몬스터 AI, 보스 AI 작업 - BehaviorTree, PDA(Primary Data Asset)
5. 시네마틱 연출 - 레벨 시퀀스
6. 레시피를 통한 무기 조합 시스템
